# hit100 — 시작하기 (전 과목 모의고사 채점·분석·보고서)

## 지금 바로 써보기 (데모 모드)
- `index.html`을 더블클릭하거나 데스크톱 앱(MockClinic)을 실행합니다.
- 회원가입 → 학원 만들기 순서로 진행하세요. "예시 학생·시험 넣기"를 켜면 기능을 바로 둘러볼 수 있어요.
- 데모 모드에서는 계정과 데이터가 **그 기기에만** 저장돼요.

## 진짜 서비스로 열기 (로그인·동기화, 무료)

### 1. Supabase (서버·로그인)
1. https://supabase.com 가입 → New project (Region: Northeast Asia (Seoul))
2. 왼쪽 **SQL Editor** → `supabase/schema.sql` 내용 전체 붙여넣기 → **Run**
3. **Authentication → Providers → Email**: 처음 테스트할 때는 "Confirm email"을 꺼두면 편해요 (출시 전에 다시 켜기)
4. **Project Settings → API**에서 `Project URL`, `anon public` 키 복사
5. `config.js`에 붙여넣기:
   ```js
   SUPABASE_URL: "https://xxxx.supabase.co",
   SUPABASE_ANON_KEY: "eyJ...",
   ```
6. **Authentication → URL Configuration**: Site URL을 `https://hit100.netlify.app` 으로, Redirect URLs에도 같은 주소 추가 (비밀번호 찾기 메일 링크가 앱으로 돌아오게)
   - 무료 요금제의 기본 메일 발송은 시간당 몇 통으로 제한돼요. 사용자가 많아지면 Authentication → SMTP에 자체 메일 서비스를 연결하세요.
7. 공용 시험을 등록할 관리자(본인) 지정: 앱에서 회원가입한 뒤 SQL Editor에서 실행
   ```sql
   insert into admins select id from auth.users where email = '내이메일@example.com';
   ```

- **안드로이드**: Chrome → 메뉴 → 앱 설치

## 사용 흐름
1. **시험** 탭 → "2026 고2 9월 학평" 검색 → 없으면 등록 (정답 숫자 붙여넣기, 3점 문항, 등급컷, 영역)
   - 관리자가 "공용 시험"으로 등록하면 모든 학원이 바로 씀
2. **학생** 추가 → 학생 페이지 **플래너**에서 시험 배정(날짜)
3. **채점**: 학생이 고른 답 입력(키보드 1~5) → 점수·등급·영역·오답 자동 → 오답 원인 체크 → ★ 3개 → 저장
4. **보고서**: 클리닉 양식 + 전체 오답표, 텍스트 복사·인쇄
5. 학생 페이지 **성적 추이 / 약점 분석 / 오답노트**, 시험 페이지 **문항 분석(상·중·하, 선지 분포)**

## 난이도 기준
정답률 50% 미만 = 상, 50~80% = 중, 80% 이상 = 하.
외부 오답률을 입력하면 그 값, 없으면 학원 응시자 3명 이상부터 자동 계산.

## 파일
- `index.html`, `app.js` — 앱
- `config.js` — 서버 설정
- `supabase/schema.sql` — DB 테이블·보안 규칙
- `manifest.json`, `sw.js`, 아이콘 — 설치형 앱(PWA)

## 문제은행 · 시험지 (v4.0)
1. **시험 등록 시 문항별 유형** 입력 (예: 독서>과학, 빈칸 추론, 수학Ⅰ>수열). 비우면 영역 이름으로 분석.
2. **문제은행 → 문제 추가**: 캡처한 문제를 클릭한 칸에 Ctrl+V(⌘+V)로 붙여넣기. 국어·영어는 "지문 세트"로 지문 + 여러 문제.
   **이미지 여러 장 추가**: 잘라둔 문제 이미지를 한 번에 올림 (한 장 = 한 문제).
3. **학생 → 약점 분석 → 취약 유형** 확인 → **맞춤 시험지 만들기**: 취약 유형별 문제를 자동으로 골라 담음.
4. **시험지**: 순서 조정 · 1단/2단 · 정답지 → 미리보기 → 인쇄(“PDF로 저장” 선택 시 PDF).
- 학원 자료로 학원 안에서 쓰는 기능이에요. 외부 문제를 올릴 땐 저작권을 확인하세요.
- 서버 모드에서는 이미지가 DB에 압축 저장돼요. 문제가 수천 개로 늘면 Supabase Storage로 옮기는 걸 권장해요.

## 학생 계정 · 플래너 · 공부 타이머 (v5.0)
1. 선생님: 학생 페이지 상단 **학생 코드 만들기** → 코드를 학생에게 전달
2. 학생: 회원가입 → "학생이에요"에 학생 코드 입력
3. 학생 화면: **오늘**(과목별 공부 타이머·오늘 할 일·7일 그래프·내 약점) / **플래너**(달력, 공부 시간 색 표시·할 일·시험 일정·시간 직접 추가) / **내 분석**(성적 추이·약점·오답노트, 보고서 열람)
4. 선생님: 학생 페이지 **공부 기록** 탭에서 달력·공부 시간 확인, 할 일(과제) 추가
